JAVASCRIPT

What is JAVASCRIPT?
HTML and CSS ------  Static webpage (Defines the structure and style of page. )
JavaScript ------- Makes the page Dynamic (Changes the content of page on basis of specified actions.);

JavaScript basically makes page come alive.

JavaScript (JS) is a programming language used to make web pages interactive.

With JavaScript, you can:
Show messages
Take user input
Create games(Snake game, 2048  game, Dice throw simulation.)
Validate forms
Change webpage content dynamically

-------------Lab 3 Important Concepts-----------
-----PopUp Boxes 
There are three main PopUp Boxes in Javascript
---Alert Boxes
It displays ->A meesage(for example: Succes or Login failed etc)
            -> OK button.
Syntax:

alert("Message written here will be displayed.");

---Confirm Boxes
It displays ->A Confirmation question("For example: Are you sure you want to delete this?, Do you want to be redirected to an external page link);
            ->OK button (returns True(in boolean datatype))
            ->Cancel button (returns False(in boolean datatype)).
Example Syntax:

ans = confirm("Are you sure?");

if(ans == true)
{
    document.write("User clicked OK");
}
else
{
    document.write("User clicked Cancel");
}
---Prompt Boxes
It displays ->Input Boxes(Takes input as string from user.)
            ->OK button (Submits the value in input box and exits popup)
            -> Cancel button(submits null in the input box and exits popup)

Example syntax:
name = prompt("Enter your name");

document.write("Hello " + name);


-------------Important Note --------------
Anything added from prompt becomes a STRING value means 

For example:

a = prompt("Enter a");   //Input--->15
b = prompt("Enter b");   //Input--->5
document.write(a + b);   //Output--->155



To convert it into integer:
use parseInt() function
Example:
a = parseInt(prompt("Enter a"));   //Input--->15
b = parseInt(prompt("Enter b"));   //Input--->5
document.write(a + b);   //Output--->20
