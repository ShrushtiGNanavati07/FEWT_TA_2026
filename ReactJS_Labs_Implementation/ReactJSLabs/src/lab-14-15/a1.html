## react - React is a JavaScript library used to build user interfaces (UI), especially for web applications. - It is mainly used to create: - Dynamic websites - Single Page Applications (SPA) - Interactive user interfaces - React was developed by Meta (formerly Facebook). - In short , React is a JavaScript library used to build fast and interactive user interfaces using reusable components. - With React: - Faster updates - Reusable components - Better performance - Easier UI management ====================================================================================================================== ## Important Features of React 1. Component-Based Architecture - React divides UI into small reusable parts called components. 2. JSX - React uses JSX (JavaScript XML). - It lets us write HTML inside JavaScript. 3. Virtual DOM - React uses Virtual DOM for fast updates. - Instead of reloading the whole webpage: Old way → Full page reload React → Update only changed part - This makes React fast. 4. Reusable Components - Write once, use many times. - react only allow one parent element - if you want to return more than one element then you should use fragment tag. => <> ===================================================================================================================== ## JSX Rules 1.
